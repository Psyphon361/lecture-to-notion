# Lecture to Notes

Turns a lecture `.pptx` into a structured draft of study notes for review, then export to Notion.

Product and engineering decisions live in `docs/HANDOFF.md` and `docs/project-brief.md`.

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm test
```

Real lecture files belong in `fixtures/private/` and are not committed.
